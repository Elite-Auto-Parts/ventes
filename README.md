# Elite Ventes

Application de vente par points pour les agents d'Elite Auto Parts (PWA, fonctionne hors ligne).

- **Vendeurs** : choisir son nom, entrer son PIN. Le portefeuille clients est téléchargé depuis le serveur, puis l'app marche sans internet.
- **Direction** : bouton « Espace Direction » sur le premier écran (clé Direction).
- Aucune donnée client n'est stockée dans ce dépôt : elles restent sur le serveur, protégées par PIN.

Publication : GitHub Pages, branche `main`, dossier racine.
